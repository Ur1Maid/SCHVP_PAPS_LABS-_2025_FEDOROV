# CumList.DesignPatterns

Мини-проект для лабораторной работы №6. Здесь собраны учебные, но предметно-ориентированные примеры паттернов GoF и GRASP для модуля **«Накопительная ведомость»**.

## Состав

- `Domain` — общие доменные модели НВ;
- `Creational` — порождающие шаблоны;
- `Structural` — структурные шаблоны;
- `Behavioral` — поведенческие шаблоны;
- `Grasp` — примеры ролей и принципов GRASP;
- `Reference/ActualProject` — небольшие реальные фрагменты из production-кода, на которые опиралась лабораторная.
