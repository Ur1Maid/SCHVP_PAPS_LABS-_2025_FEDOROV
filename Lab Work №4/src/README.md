# Lab Work №4 / src

В этой папке собраны реальные фрагменты проекта, на которые опирается отчёт по 4-й лабораторной работе.

## Структура

- `frontend/graphql` — реальные GraphQL-операции из `automatic-dispatch-frontend`
- `backend/cumlist-app-service` — мутации и схема командного сервиса
- `backend/del-cumlist-data-service` — query-операции и схема сервиса чтения
- `backend/cumlist-normalize-service` — внутренние GraphQL-запросы слоя нормализации
- `postman` — готовая коллекция Postman и environment
- `schema` — краткая сводная схема публичного GraphQL API модуля НВ
  и небольшой extract из `coreSchema.graphql`, использованный только для уточнения подписки

## Важно

Коллекция Postman подготовлена под реальный GraphQL-контракт, но для получения скриншотов из Postman нужно:
1. поднять нужные сервисы у себя локально;
2. заполнить переменные окружения;
3. выполнить запросы;
4. сохранить скриншоты и при необходимости вставить их в `docs/LabWork4.md`.

Дополнительно общая `coreSchema.graphql` использовалась не как основной источник по НВ, а только для проверки того, что подписка `entityOperationResult(correlationId: UUID!): String!` действительно является частью общего GraphQL-контракта платформы.
